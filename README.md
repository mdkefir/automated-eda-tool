# 📊 Automated EDA Tool

**Программный модуль для автоматизации разведочного анализа данных (Exploratory Data Analysis).**

Приложение позволяет загрузить любой датасет (CSV/Excel) и мгновенно получить детальный статистический отчет, визуализацию распределений и автоматические инсайты о качестве данных.

---

## 🚀 Возможности

*   **📁 Умная загрузка данных:**
    *   Поддержка форматов `.csv` и `.xlsx`.
    *   Автоматическое определение кодировок (`utf-8`, `cp1251`, `latin1`).
    *   Обработка ошибок парсинга (пропуск "битых" строк).
*   **📋 Обзор и Статистика:**
    *   Расчет базовых метрик (размерность, дубликаты, типы данных).
    *   Анализ пропущенных значений (Missing Values).
    *   Описательная статистика для числовых и категориальных признаков.
*   **💡 Автоматические инсайты:**
    *   Детекция константных столбцов.
    *   Предупреждения о высоком проценте пропусков.
    *   Поиск сильной корреляции (мультиколлинеарность).
    *   Выявление дисбаланса классов.
*   **🎨 Интерактивная визуализация:**
    *   Гистограммы и Boxplot'ы.
    *   Матрица корреляций (Heatmap).
    *   Scatter plots и Bar charts.
*   **🛠 Работа с выбросами:**
    *   Поиск аномалий методом межквартильного размаха (IQR).
    *   Возможность очистки данных и скачивания обработанного файла.

## 🚀 Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/mdkefir/automated-eda-tool.git
   cd automated-eda-tool
   ```

2. **Создайте виртуальное окружение:**
   ```bash
   # Windows
   python -m venv venv
   venv\Scripts\activate

   # Mac/Linux
   python3 -m venv venv
   source venv/bin/activate
   ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Запустите приложение:**
   ```bash
   streamlit run app.py
   ```
